# re-sPLAY v0.8.12 — First preview

A native macOS menu-bar app for choosing which displays to use without unplugging cables.

## Download and install

Download **re-sPLAY-v0.8.12-macos27-arm64.zip** from Assets, unzip it, and drag **re-sPLAY.app** into Applications. No Xcode, Command Line Tools, or build step is required. Requires **Apple silicon and macOS 27+**; Intel Macs are not supported.

The ZIP includes an installation guide. `INSTALL.md` and `SHA256SUMS.txt` are also available separately. The Source code archives are optional developer downloads.

**First-open notice:** this preview is ad-hoc signed, not Developer ID signed or notarized. If macOS blocks it as an unverified developer and you trust the download, use **System Settings → Privacy & Security → Open Anyway** after attempting to open the app. Follow [Apple's instructions](https://support.apple.com/en-us/102445). Managed Macs may disallow this exception.

## Included

- Activate one monitor exclusively and restore displays from the window, menu bar, or global shortcuts.
- Per-display brightness, native HDR brightness where supported, and auto-brightness controls for supported Apple displays.
- Native sidebar window, monitor previews, selected-monitor glow and badge, smooth transitions, and clear action buttons.
- Quick Controls in the menu bar and optional launch at login.
- Local preferences; no analytics or automatic diagnostic uploads.

## Preview limitations

- Uses private macOS display APIs; compatibility can change with macOS updates.
- Tested on Apple silicon with Apple Studio Displays and an ASUS PG32UCDM through Thunderbolt connections. Other hardware, docks, and DDC/CI support may behave differently.
- Disconnection requests standby; it does not cut AC power. Brightness 0% means the display's minimum, not power off.
- No saved workspace/window-position recall, automatic app updater, Intel build, or notarization in this release.
- Overnight sleep/wake and arbitrary hot-plug behavior have not been exhaustively validated.

Quit the app normally to restore displays it disabled. Full usage, recovery steps, privacy details, and validation limits are documented in README.md, PRIVACY.md, and TESTING.md in the repository.

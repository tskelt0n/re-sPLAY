# README previews

The version 0.8.0 previews were captured from the installed native app on October 12, 2026:

- `readme-banner.png`: main window in the system's dark appearance.
- `app-light.png`: main window using the app's temporary light-appearance preview flag.
- `quick-controls.png`: the menu-bar popover in light appearance.

All three displays are active, with their actual brightness readings shown. No monitor settings were changed to stage these captures. The images are unedited app-window captures, replacing the earlier generated promotional banner so the README reflects the current interface accurately.

The monitor previews inside the app use original bundled illustrative wallpaper; they are not live screen captures. See [wallpaper provenance](../../Assets/README.md) and [brand assets](../brand/README.md).

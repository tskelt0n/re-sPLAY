# Display preview artwork

`DisplayWallpaper.png` is original illustrative artwork created with the built-in image-generation tool. It is used inside the native monitor illustrations, never as a live preview of the user's desktop.

## Generation prompt

```text
Create an original wallpaper image for miniature monitor previews inside a native macOS display-management app. Wide 16:9 landscape, abstract layered mountain silhouettes around a still lake at dusk, rich violet and indigo lower slopes, soft lavender and pale peach sky, quiet elegant atmospheric depth. Smooth clean photographic-illustration hybrid, restrained detail so it reads beautifully inside a small monitor frame. A subtle light horizon and darker foreground create depth. No computer, device frame, user interface, icons, buildings, people, lettering, logos or watermark. Full opaque landscape image only. It must be original artwork, not a copy of an Apple wallpaper.
```
